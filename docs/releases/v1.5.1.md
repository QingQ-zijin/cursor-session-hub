v1.5.1：Cursor 风格阅读细节与基于会话的 API 聊天。

- 移除窗口右上角的黑色背景；收紧问答间距，连续助手消息减少重复标签，工具记录使用紧凑的命令/路径摘要，点击后读取详情。
- 会话页面可以真正聊天：默认引用当前会话，支持 `@` 搜索选择其他会话、流式显示回复、停止生成、恢复读取和个人聊天历史。
- 管理员可配置 OpenAI 兼容 API 的地址、密钥、模型、引用预算和输出额度。本地/团队配置独立，团队密钥不下发成员客户端。
- 长会话从索引选取相关及近期片段，发送前显示引用范围；最多五个引用、每人一个生成、服务合计两个，不影响原来的单任务解析策略。不执行历史工具命令，不修改 Cursor 原始记录。
- 更新检测优先使用随 Release 发布的静态 `update.json`；限流时显示状态和重试时间，不再持续请求匿名 GitHub API。旧版检查失败时请手动安装本版一次。

Windows x64、Mac Apple Silicon、Mac Intel 各有对应安装包。管理员填写实际服务商 API 后即可启用聊天；接口测试使用本机模拟模型，不包含付费 API 或预置密钥。安装升级保留原有记录。

配置步骤与资源边界见仓库 `docs/AI_CHAT.md`。网页端需同步部署服务端本版；客户端不会自动替你升级服务器。

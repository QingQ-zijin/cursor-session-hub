Cursor Session Hub v1.1（安装包版本 1.1.0）。

- 本机 Cursor 会话按工作区分组并可筛选，使用 Cursor 保存的会话标题；UUID 和原始路径移到来源详情。同一会话的 JSONL 副本默认隐藏，可手动显示。自定义标题不会被扫描覆盖。
- 已展开轮次自动接续读取所有消息、内容块和长正文，不再需要逐页点击“下一段”。默认最近 3 轮、最多同时展开 3 轮；其他轮次仍按需加载。接口仍保持分页，长内容最多同时读取 2 个分块。
- 修正 HTML/Markdown 导出：正常展示问答、标题、表格、代码及工具记录，不将 JSONL 外层结构当正文。HTML 内置公式渲染和字体，离线打开也可阅读。
- 支持导入 JSONL、Markdown、HTML 和文字型 PDF。PDF 按页导入原文；没有文字层的扫描页显示需要 OCR 的诊断，加密文件要求先解密。PDF 文件上限 64 MiB，单个文本块上限 8 MiB，所有解析仍在后台受限进程执行。
- 保留手动团队同步、评论、收藏、成员管理和 GitHub 正式版更新检测。

核对原始长 JSONL 的 949 段 AI 文字：HTML 导出再导入后逐段一致；Markdown 导出中的文字及顺序一致。

Windows 选择 `x64-setup.exe`，M 系列 Mac 选择 `aarch64.dmg`，Intel Mac 选择 `x64.dmg`。关闭旧客户端后运行新版安装包，已有记录与设置保留。升级后在“本机记录”中重新发现记录，即可更新工作区和 Cursor 标题。

Cursor Session Hub 的首个公开发布版本。支持 Windows x64、Mac Apple Silicon 和 Mac Intel。

- 修复本地与团队空间切换时沿用另一空间会话 ID，导致“会话不存在或已撤销共享”的问题。
- 切换后立即显示加载状态；旧请求不会覆盖当前列表或重新打开上一空间的会话。加载失败可直接重试。
- 客户端启动时、运行中每 6 小时自动检查 GitHub 正式 Release；发现新版显示提示。点击左下角版本号也可手动检查，查看说明并下载适合当前平台的安装包。
- 包含管理员删除成员功能；已删除账号的登录与同步凭证立即失效，已有协作记录保留署名占位。
- 保留离线导入、Cursor 解析、长会话按需加载、手动同步、团队权限、评论、收藏及导出。

安装：Windows 下载 `x64-setup.exe`；M 系列 Mac 下载 `aarch64.dmg`；Intel Mac 下载 `x64.dmg`。旧用户运行新版安装包即可升级，本地记录与设置保留。0.1.2 及更早版本需先手动安装此版，之后可自动检测更新。

更新提示不自动执行安装包；确认后从本仓库 GitHub Releases 下载。仅检测正式版，不推送草稿或预发布版。发布附件含 SHA256 校验文件及 MIT 许可证。本团队测试版本未购买商业签名证书或 Apple 公证。

v1.5：Cursor 风格的会话预览工作台。

- 参照提供的 Cursor 界面重做浅色背景、顶部菜单、单一侧栏和中央预览入口。工作区与会话合并为可折叠的树状列表，保留原始会话标题。
- 工作区侧栏支持左侧/右侧停靠和收起；Ctrl / Cmd B 切换侧栏，Ctrl / Cmd K 搜索会话。
- 最多打开6个会话标签，切换时只挂载当前会话的阅读内容。默认最近3轮、完整正文自动分块读取、工具记录延迟展开继续保留。
- 问答、代码块、工具记录和公式采用统一的工作台排版；代码块提供语言标签和复制按钮。
- 顶部菜单和入口对应实际的导入、搜索、同步与设置功能。此产品用于预览和协作，不运行对话中的命令，不提供 Cursor Agent 的模型执行功能。
- 保留本地/团队切换、账号权限、评论收藏、手动同步，以及 Markdown、HTML、PDF 导入导出。适配浅色、深色和手机窄屏。

Windows、Mac Apple Silicon、Mac Intel 分别下载对应安装包。已有数据和设置保留，服务器网页端刷新即可使用部署后的版本。

v1.5.3：工作区批次同步与最终回答聚焦。

- 未命名及其他来源默认折叠，按需展开；本地列表中的未命名记录也默认收起。
- 工作区可一键同步全部独立会话，不受列表分页限制；支持一键同步 Cursor 左栏全部工作区的已命名会话。
- 直接读取 Cursor 工作区归属和会话目录，排除归档、内部子代理和重复 JSONL 副本。保留空工作区；已有导入记录不会被自动删除。
- 默认同步到本地库，可切换团队服务器。批次持久化、逐条解析和上传，支持暂停、继续、取消、失败明细和重试，不扩大原有解析并发。
- 默认收起最后一次工具调用前的中间说明、思考与执行过程，展开其后的完整回答。支持同一消息内的混合内容块；没有明确边界时保留文字，不编造最终结论。
- 保留缩放、回收站、评论、收藏、Markdown/HTML/PDF 导出和静态更新检测。

Windows x64、Mac Apple Silicon、Mac Intel 分别下载对应安装包。用法与同步范围见 docs/WORKSPACE_SYNC.md。

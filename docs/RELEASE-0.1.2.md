# 0.1.2 成员删除

管理员可在“成员管理”中删除其他成员或管理员。确认框明确说明：账号及登录凭证、个人收藏、关联邀请会被删除，待处理任务和未完成上传会取消；已共享的会话和评论保留，并显示为“已删除成员”。管理员不能删除当前登录账号，系统始终保护至少一名有效管理员。

删除后的账号立即失去网页登录和客户端访问权限。同名新账号使用全新的身份ID，不会继承旧会话的修改权限。取消、停用与永久删除是不同操作，删除后账号不再出现在成员列表。

新增测试覆盖权限拒绝、浏览器Cookie与客户端令牌撤销、历史内容保留、同名账号隔离、两个管理员并发删除，以及删除期间上传组装不能继续发布。生产验收脚本也会删除自己创建的测试账号，避免再次留下停用测试用户。

验证结果：68项后端测试、4项前端测试和生产构建通过；实际网页删除确认、取消、自身账号保护及窄屏布局7项检查通过。清理5个既有测试账号后，数据库复核确认相关账号、令牌、个人收藏及邀请均已清理，保留的共享历史未被删除。

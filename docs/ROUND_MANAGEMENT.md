# 轮次目录与回收站

右侧「更早的会话」列出当前版本的轮次，每页最多 100 条，点击后读取正文，最多同时展开三轮。窄窗口下点击阅读工具栏的目录图标打开右侧抽屉。

将鼠标移到轮次标题或右侧目录条目，可使用垃圾桶按钮。可以填写删除说明；确认后轮次移到回收站，正文不再显示。在右侧回收站中可以编辑备注或恢复轮次。团队空间只有会话所有者和管理员能修改；其他成员可阅读备注。

删除记录绑定会话版本和原始轮次编号，不修改 Cursor 数据库/JSONL，也不把标记自动套用到改写后的新版本。恢复保留原始消息、工具记录、图片、评论及收藏定位。已有下载文件与历史同步版本不会被远程抹除。

新导出和新同步包排除当前版本中已移到回收站的轮次及其独有附件。同步到服务器是手动操作，本地删除不自动改动云端旧版本。同步或导出正在进行时，完成或取消该任务后再修改轮次，避免产生混合结果。

执行记录默认合并为收起的摘要，展开后再读取工具输入和输出。`Worked for` 时间取自已有记录的时间跨度；没有可靠时间时只显示记录数量，不编造执行耗时。问答文字仍完整显示。

## 缩放与界面

Ctrl/Cmd + `+`（或 `=`）放大，Ctrl/Cmd + `-` 缩小，Ctrl/Cmd + `0` 恢复 100%；比例范围 67%–175%，同一设备自动记住选择。View 菜单也有缩放和主题入口。Windows/macOS 桌面使用原生 WebView 缩放，网页使用页面缩放样式。

顶部只有一个「同步」按钮，支持当前会话或勾选的多条会话；旁边的下载图标打开任务与导出下载。File 菜单导入文件，工作区标题旁的文件夹加号发现本机 Cursor 会话。

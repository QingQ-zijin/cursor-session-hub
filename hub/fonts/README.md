# Noto Sans SC for PDF exports

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The upstream `NotoSansSC[wght].ttf` SHA256 is
`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`.
The bundled static TrueType instances use `fontTools.varLib.instancer` at
`wght=400` and `wght=700`, retaining the original character coverage.
PDF output embeds only used glyphs. No system font installation or online
font request is required. License: SIL OFL 1.1, reproduced in `OFL.txt`.

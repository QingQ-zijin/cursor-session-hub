# Upstream foundation

Cursor Session Hub is based on `tim-hua-01/cc_transcript_viewer`, commit `d5ef2e4`, together with the current local import and round-pagination changes made before this product was created.

The original MIT license and attribution to Tim Hua are retained in LICENSE. The original viewer remains available through `server.py`; product services run through `python -m hub`.

Personal transcripts, browser screenshots and credentials are excluded from the source repository.
# PDF font

PDF exports embed a subset of Noto Sans SC from Google Fonts, licensed under
the SIL Open Font License 1.1. Bundled regular/bold TrueType instances were
generated from the upstream variable font at weights 400 and 700.
See `hub/fonts/OFL.txt` and `hub/fonts/README.md` for attribution and provenance.
